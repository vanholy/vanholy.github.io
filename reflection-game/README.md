# reflection-game

Gioco nel browser per misurare i **tempi di reazione**, pensato per tablet.

Si illumina un bersaglio dopo un'attesa casuale: toccalo il più in fretta possibile.
Il gioco mostra il tempo di ogni reazione, la media, gli errori e salva lo storico delle partite sul dispositivo.

## Come si gioca

Apri `index.html` nel browser (o https://vanholy.com/reflection-game/) e premi **Inizia**.

## Opzioni

- Modalità: bersagli visibili / bersagli che compaiono
- Dimensione e numero dei bersagli
- Frequenza: lenta, media, veloce (l'attesa resta sempre casuale)
- Numero di interazioni per partita

Il progetto completo è descritto in [PROGETTO.md](PROGETTO.md).
